Simple Setup Guide for Phones

Easiest Method: Use VLC on Phone

No GStreamer needed on phones! Just use VLC Media Player which is available on all platforms.

  1. On your laptop: Run the server command shown above (copies system audio)
  2. On your phone: Install VLC from App Store / Play Store
  3. In VLC: Go to Network → Open Network Stream
  4. Enter: rtp://@224.0.0.1:5004
  5. Adjust sync in VLC: Tools → Track Synchronization → Set audio delay to -500ms
rtp://@<YOUR_PC_IP>:5004

Replace <YOUR_PC_IP> with your computer's IP shown above (e.g., 192.168.1.100)

Alternative: GStreamer on Android (Termux)

For advanced users who want the exact pipeline:

  1. Install Termux from F-Droid
  2. Run: pkg install gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad gst-plugins-ugly opus
  3. Paste the client command from the Host Studio tab

Important Notes

  • Same WiFi Required: Your phone and laptop must be on the same local network
  • Firewall: Allow incoming UDP connections on port 5004
  • Audio Quality: Server uses Opus music-mode at 160kbps for excellent quality
  • Stable Delay: 500ms buffer ensures no dropouts, adjust VLC audio delay to match video
