GStreamer Low-Latency Setup & Tuning Guide

Windows WASAPI Setup

1. Install GStreamer for Windows from freedesktop.org (Choose Complete installation).

2. WASAPI loopback automatically captures whatever movie player (VLC, mpv, Chrome) is playing audio through your speakers.

gst-launch-1.0 -v wasapisrc loopback=true ! audioconvert ! audioresample ! audio/x-raw,rate=48000,channels=2 ! opusenc frame-size=10 bitrate=160000 ! rtpopuspay ! udpsink host=224.0.0.1 port=5004 auto-multicast=true

Linux PulseAudio / PipeWire Setup

1. Install packages: sudo apt install gstreamer1.0-tools gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-opus

2. Find your desktop loopback monitor device:

pactl list sources short | grep monitor

3. Use the monitor device string in the server command pipeline.

macOS CoreAudio Setup

1. Install BlackHole virtual audio driver via Homebrew: brew install blackhole-2ch

2. In macOS Audio MIDI Setup, create a Multi-Output Device sending audio to both your speakers and BlackHole 2ch.

Lip-Sync Optimization Tips

  • Use Ethernet Cables: Wi-Fi introduces jitter spikes (20ms–60ms). Ethernet keeps LAN latency under 2ms.
  • 10ms Opus Frames: Keeps algorithmic latency at ~5ms without overloading CPU.
  • Minimizing Jitter Buffer: Set rtpjitterbuffer latency=10. If dropouts occur, increase to 20ms.
